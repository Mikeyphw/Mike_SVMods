# BirdsOfAFeather integration (WildEggsHatching refactor)

This refactor depends on **BirdsOfAFeather** as a required dependency.

## Guardrails
- WildEggsHatching will fail-fast if BirdsOfAFeather isn't installed.
- WildEggsHatching will fail-fast if BirdsOfAFeather is copied into this mod folder (no local duplicates).

## Shared utilities used
- Mikew.BirdsOfAFeather.Framework.Random.* (shared RNG primitives).
